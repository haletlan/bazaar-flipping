odhad zisku za hodinu
Načítám data z bazaaru…

Jak se počítá: buy order dáš o 0,1 nad nejvyšší existující, sell offer o 0,1 pod nejnižší. Zisk za kus je prodejní cena po dani mínus nákupní. Zisk za hodinu = zisk za kus × počet kusů, který reálně stihneš za hodinu (tvůj podíl z menšího z obou týdenních objemů ÷ 168), omezený kapitálem. Je to odhad: konkurence může tvůj order během minuty přebít.

Rizikové = marže nad 40 % nebo méně než 3 konkurenční ordery, což často znamená manipulaci s cenou nebo item, který se těžko prodává.

Není spojeno s Hypixel Inc. ani jím schváleno. Data: api.hypixel.net (bez API klíče).
